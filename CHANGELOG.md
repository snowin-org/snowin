# Changelog

## 0.1.0 - unreleased

This is the first release-oriented SnowIn package line. It includes the
xarray-native scientific contracts, canonical phase-to-dSWE kernel, NISAR GUNW
adapter, COP30/local-incidence geometry, reference-phase and temporal APIs,
named support layers, metrics, diagnostics, plotting scaffolding, and the
downstream Colorado integration boundary.

The package is not yet published to PyPI or Conda. Real-product Colorado
migration remains gated by phase-lineage evidence and external-data validation.
